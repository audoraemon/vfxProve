Death second review art (2026-11-16) - PixelLab sources and prompts. 65 generations (balance 1253 -> 1188).
Run everything from the repo root.

  grasping hand   python tools/dev/pixellab_src/death_review_2/pack_hand.py
                  -> assets/pixellab/fx/grave_hand/grave_hand.png + grave_hand.json (R34)
  pale ghost      python tools/dev/make_animal_sheet.py --src tools/dev/pixellab_src/death_review_2/pale_ghost --out assets/pixellab/animals/pale_ghost.png
  skeleton        python tools/dev/make_animal_sheet.py --src tools/dev/pixellab_src/death_review_2/skeleton --out assets/pixellab/animals/skeleton.png
  ghoul           python tools/dev/make_animal_sheet.py --src tools/dev/pixellab_src/death_review_2/ghoul --out assets/pixellab/animals/ghoul.png

Character folders (pale_ghost/, skeleton/, ghoul/) are laid out from each character's get_character ZIP by
layout_char.py: rot_<dir>.png and <anim>/<dir>_<i>.png, every image centred on a transparent 48x48 canvas (padding
only, no scaling) because PixelLab stores the rotations and the animations on different canvases (24/28 vs 32/40).
The run animations are saved as walk/ (make_animal_sheet.py reads walk/ and bite/). Extra folders (grab2/, grab3/)
are rejected takes, ignored by the packer. Sheet rows: still SE/NE, walk SE, walk NE, bite SE (8 frames each).

Why the characters are small: v3 draws the figure to fill its canvas (a 48 px v3 character is ~46 px tall, 2.5x a
~18 px townsperson), so the figures were made at 28/24 px and padded to the 48 cell to read 1:1 (R38/R42).
